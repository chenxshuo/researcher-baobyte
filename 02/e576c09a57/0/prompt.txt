## Goal

Build the first working frontend version of Nobli.

Nobli is a frontend-first, mock-first but backend-ready agentic workspace for AI research scientists and researchers writing papers. The product should feel like a serious AI research scientist operating system, not a static dashboard, not a marketing landing page, and not a generic AI playground.

The first version should include two major states:

1. Home / New Task Input Screen
2. Running Agent Workspace

Use React + TypeScript.

Use mock data only for now, but structure the frontend so it can connect to backend APIs later through service functions.

Do not implement backend logic inside React components.

Do not create API routes, backend services, authentication, database, or production infrastructure.

Only create frontend service wrappers that can later call APIs.

